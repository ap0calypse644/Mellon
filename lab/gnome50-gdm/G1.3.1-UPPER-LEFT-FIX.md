## Visual finding (2026-11-12)

Actual GDM screenshots at approximately 1484×928 show the photo,
upper-right constellation, lower-left clock, lower-right mapping status,

## Proven geometry bug

The approved M8.3.2 `hud-layout.js` reserves the top-left corner for
a `SHOW LOGIN` control, but GDM's native login form has no such
control. The reused layout places the top-left HUD at `y=80`, height
`54`, ending at `y=134`. At 1484×928, the photo-safe center begins
at `y=129.92`. Its overlap triggers the layout's protection rule,
causing the panel to be hidden entirely. The GDM-specific correction
uses `y=14` and `recovery=null`. The upper-left panel is now fully
above the center-safe inset, and avoids GNOME's top-center clock.
**The M8.3.2 user lock screen layout remains byte-for-byte unchanged.**

## Change scope

Exactly ONE previously installed system extension file is replaced:
`/usr/share/gnome-shell/extensions/mellon-greeter@local/hud-layout.js`

The existing photos, source stars, metadata, HUD actor tree, 5-second
grid logic, enabled-extensions, GDM dconf and original user
`mellon-lab@local` code are not changed.
