# G1.3 — Observatory HUD and recurring scan (source-only preview)

The real GDM photo-only integration **G1.2.1 visually passed** in the
VM on 2026-11-12. Its nebula appears on both user-selection and
password screens; GDM's native controls remain visible.

This change is the next **uninstalled source-only** prototype:

- Imports the ORIGINAL approved `hudMetadata` and `ObservatoryHUD`
  from the M8.3.2 user lock-screen presentation system.
- Reuses the M8.3.2 `hud-layout`, `hud-progress`,
  `hud-intro-state`, `observatory-intro`, and `stylesheet.css`
  byte-for-byte. It draws the four cyan/violet Observatory instrument
  panels and the same non-reactive 5-second left-to-right scan.
- Mounts the HUD actor as a sibling **below the actual native
  LoginDialog** inside `Main.screenShield._lockDialogGroup`, above
  Mellon's existing photo sibling. Unlike G1.1, it does NOT attempt to
  insert children into `LoginDialog`, whose GNOME 50 custom allocation
  only manages native login controls.
- No GDM password buffer, keyboard event, verifier, PAM, user list,
  focus or login behavior is observed/changed.
- The mapping HUD is initially `AWAITING INPUT` (8 empty segments).
  GDM-specific visual mapping is intentionally deferred to a separate
  review: **G1.3 does not pretend an authentication state** or trigger
  star illumination from fake typed input.
- At greeter teardown, the HUD destroys its timers/actors before
  Mellon removes its photographic background.

**IMPORTANT:** No user instruction to install this G1.3 source has
been issued. The running, verified VM greeter is still G1.2.1.
This commit updates *repository source and CI only*, not GDM, the VM,
or BlackPearl GNOME. Before deployment, author a versioned guest-only
installer with rollback and SHA256 pack verification, and test it in
the isolated VM. Do not reuse the G1.2.1 updater because its specific
`extension.js` signature guard deliberately refuses a different
installed build.

## What G1.3 will display

The existing photographic background, the approved top-left/top-right/
bottom-left/bottom-right Observatory panels, the local clock, eight
unlit mapping segments, and the M8.3.2 full-screen five-second grid.
